# Agentic AI Engineering Journey

A project-based learning repository for developing Python, software engineering,
backend development, and agentic AI skills.

## Day One: Sensor Summary CLI

The first exercise analyzes a collection of sensor readings.

It calculates:

- Number of samples
- Minimum reading
- Maximum reading
- Average reading
- Number of readings above a specified threshold

## Run the program

Create and activate a Python virtual environment:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Run the program:

```powershell
python .\sensor_summary.py
```

## Expected output

```text
Samples: 4
Minimum: 72.1
Maximum: 120.5
Average: 84.95
Alerts: 1
```
